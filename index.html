10.1～10.3 單一形狀慣性矩

面積慣性矩：Ix=∫y²dA，Iy=∫x²dA
平行軸定理：I = IG + A d²
迴轉半徑：k = √(I/A)
dy 是形心到欲求 x 軸的垂直距離；dx 是形心到欲求 y 軸的水平距離。

曲線面積直接解題

這頁就是為了像 y = √x、0 ≤ x ≤ 1 這種題目做的。 不用再輸入 custom 面積，直接輸入曲線方程式與範圍即可。
A = ∫[y上 − y下] dx
x̄ = (1/A) ∫x[y上 − y下] dx
ȳ = (1/A) ∫1/2[y上² − y下²] dx
Ix = ∫1/3[y上³ − y下³] dx，Iy = ∫x²[y上 − y下] dx
可用：sqrt(x)、sin(x)、cos(x)、tan(x)、exp(x)、log(x)、abs(x)、pi。x^0.5 也可以。
預設使用「課本圖模式」：只畫陰影面積、座標軸、尺寸 1 m，不顯示形心線。

工程截面快速建模

可辨識關鍵字：I型鋼 / T型 / 中空矩形 / 矩形 / 圓形 / 圓管，以及 H、B、b、bf、tf、tw、D、d 等尺寸。
系統內部計算邏輯：
1. 將工程截面拆成矩形 / 圓形 / 孔洞等子面積。
2. 對每個子面積求 A、x̄i、ȳi、IxGi、IyGi。
3. 求整體形心：x̄ = Σ(Ai x̄i)/ΣAi，ȳ = Σ(Ai ȳi)/ΣAi。
4. 平行軸定理：Ix = Σ(IxGi + Ai(ȳi−ȳ)²)，Iy = Σ(IyGi + Ai(x̄i−x̄)²。
5. 轉動半徑：kx = √(Ix/A)，ky = √(Iy/A)。

10-9 扇形 / 極座標慣性矩

這頁是為了習題 10-9 補強的題型。陰影面積為圓扇形，半徑為 r₀， 角度從 −α/2 到 +α/2，對稱於 x 軸。適合用極座標直接求 Ix、Iy。
極座標：x = r cosθ，y = r sinθ，dA = r dr dθ
範圍：0 ≤ r ≤ r₀，−α/2 ≤ θ ≤ +α/2
Iy = ∫x²dA = ∫∫(r cosθ)² r dr dθ = r₀⁴(α + sinα)/8
Ix = ∫y²dA = ∫∫(r sinθ)² r dr dθ = r₀⁴(α − sinα)/8
注意：公式中的 α 必須使用弧度。如果你選「度」，程式會自動換算成弧度。 題目若沒有給數字，可按「只顯示符號公式」作為解題推導。

10.5～10.7 慣性積、傾斜軸與莫耳圓

Ix' = (Ix+Iy)/2 + (Ix-Iy)/2 cos2θ - Ixy sin2θ
Iy' = (Ix+Iy)/2 - (Ix-Iy)/2 cos2θ + Ixy sin2θ
Ix'y' = (Ix-Iy)/2 sin2θ + Ixy cos2θ
正角度表示座標軸逆時針旋轉。不同課本的 Ixy 正負圖示可能不同，請以本頁公式為準。

10.8 質量慣性矩

質量慣性矩：I = ∫r²dm
平行軸定理：I = IG + m d²
質量迴轉半徑：k = √(I/m)
