10.1～10.3 單一形狀慣性矩

面積慣性矩：Ix=∫y²dA，Iy=∫x²dA
平行軸定理：I = IG + A d²
迴轉半徑：k = √(I/A)
dy 是形心到欲求 x 軸的垂直距離；dx 是形心到欲求 y 軸的水平距離。

10.4 組合面積的慣性矩

每一列代表一個子面積。x̄、ȳ 請輸入該子面積的「形心座標」。 如果是挖孔，類型選「扣除孔洞」即可。
rect 使用 b,h；circle 使用 d；tube 使用 d,D；custom 使用 A,IxG,IyG,IxyG。
單位可用 mm、cm、m，但全題要一致。

10.5～10.7 慣性積、傾斜軸與莫耳圓

Ix' = (Ix+Iy)/2 + (Ix-Iy)/2 cos2θ - Ixy sin2θ
Iy' = (Ix+Iy)/2 - (Ix-Iy)/2 cos2θ + Ixy sin2θ
Ix'y' = (Ix-Iy)/2 sin2θ + Ixy cos2θ
正角度表示座標軸逆時針旋轉。不同課本的 Ixy 正負圖示可能不同，請以本頁公式為準。

10.8 質量慣性矩

質量慣性矩：I = ∫r²dm
平行軸定理：I = IG + m d²
質量迴轉半徑：k = √(I/m)
